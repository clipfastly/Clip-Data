Your MongoDB problem is clear: **MongoDB is failing because you are running Linux kernel `7.0.0-34`, while your installed MongoDB version refuses kernels `6.19+`.**

 You already have an older compatible kernel installed: `6.8.0-142-generic`.

 ### Do this now

 1. **Reboot:**

```
sudo reboot
```

 2. At the GRUB menu, select:\
    **Advanced options for Ubuntu → Ubuntu, with Linux 6.8.0-142-generic**
3. After login, verify:

```
uname -r
```

 It should show:

```
6.8.0-142-generic
```

 4. Start MongoDB:

```
sudo systemctl start mongod
sudo systemctl status mongod
```

 5. Test:

```
mongosh
```

 **Do not reinstall MongoDB or delete `/var/lib/mongodb`.** Your logs indicate a kernel compatibility issue, not a database-data problem.
